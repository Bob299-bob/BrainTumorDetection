# Brain Tumor Detection

Deep Learning based Brain Tumor Detection using CNN and Streamlit.

## Features
- MRI Image Upload
- Brain Tumor Prediction
- CNN Deep Learning Model
- User-friendly Streamlit Interface
- Fast and Accurate Detection

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Streamlit

## Live Demo
https://braintumordetection-nojexgyvqy4atl6ckkpdrs.streamlit.app/

## Project Description
This project uses Convolutional Neural Networks (CNN) to detect brain tumors from MRI images. Users can upload MRI scans through a Streamlit web application, and the trained deep learning model predicts whether a tumor is present or not.
